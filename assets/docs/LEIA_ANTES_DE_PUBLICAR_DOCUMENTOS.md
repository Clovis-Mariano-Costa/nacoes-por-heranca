# Atenção antes de publicar documentos

Os documentos de Estatuto e Ata podem conter RG, CPF, endereços pessoais, assinaturas e outros dados protegidos.

Antes de publicar no site, gere uma versão pública sanitizada, removendo ou ocultando dados pessoais que não sejam indispensáveis ao interesse público institucional.

Também é recomendável revisão humana antes da publicação.
